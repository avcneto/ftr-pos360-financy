# Financy frontend

React, Vite, TypeScript, GraphQL, Tailwind CSS, React Query and React Hook Form.

Copy `.env.example` to `.env` and set `VITE_BACKEND_URL` to the GraphQL endpoint. Run `npm ci` and `npm run dev` to start locally. The backend must be running with its database initialized.

Use `npm run build`, `npm run lint` and `npm run test` to verify changes.
